# Kajal's Portfolio Website

A responsive personal portfolio website built with **HTML5** and **CSS3**.  
This project serves as a digital résumé showcasing skills, projects, and contact information.

---

## 🚀 Features
- **Profile/Hero Section**: Name, role title, and avatar placeholder
- **About Me Section**: Brief introduction and background
- **Skills Section**: Visual grid of technical skills
- **Projects Section**: Two project cards with descriptions and GitHub links
- **Contact Section**: Email and social links (LinkedIn, GitHub)
- **Smooth Scroll Navigation** between sections
- **Consistent Branding** with a purple/blue gradient theme
- **Responsive Layout** for desktop and mobile

## 🎨 Design Notes
- **Colour Scheme**: Gradient hero (purple → blue), neutral gray backgrounds, white cards
- **Typography**: 
  - Headings: bold, larger font sizes
  - Body: clean sans-serif for readability
- **Layout**: Flexbox grids for skills and projects, responsive stacking on mobile

---

## 📱 Responsiveness
- Desktop: Multi-column grids for skills/projects
- Tablet/Mobile: Stacked layout with adjusted font sizes
- Smooth scroll ensures easy navigation across devices

---

## 🛠️ Tech Stack
- **HTML5** for semantic structure
- **CSS3** for styling and responsive design
- *(Optional)* JavaScript for future enhancements (animations, interactivity)

---

## 📖 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Replace placeholder text, images, and links with your own details.
