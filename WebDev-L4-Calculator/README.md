# 🧮 Browser-Based Calculator

A fully functional calculator built with **HTML5**, **CSS3 (Grid)**, and **Vanilla JavaScript**.  
This project provides a user-friendly interface for performing basic arithmetic operations directly in the browser.

---

## 🚀 Features
- **Display Screen** showing current input and results
- **Numeric Buttons** (0–9) and decimal point
- **Operator Buttons**: addition (+), subtraction (−), multiplication (×), division (÷)
- **Equals (=) Button** to evaluate expressions
- **Clear (C) Button** to reset the display
- **Backspace/Delete Button** to remove the last character
- **Division-by-Zero Handling** with error message
- **Operator Chaining** (e.g., `5 + 3 × 2`) without reset
- **CSS Grid Layout** for clean button alignment
- **Event Listeners** (no inline `onclick` attributes)

## 📖 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Use the buttons to input numbers and operators.
4. Press **=** to evaluate, **C** to clear, or **⌫** to delete the last character.
