# OIBSIP

This repository contains five beginner‑friendly web development projects built with **HTML5**, **CSS3**, and **JavaScript (Vanilla)**.  
Each project focuses on a specific skill set — from static layouts to interactive tools — and together they form a solid foundation for front‑end development practice.

---

## 📑 Projects Overview

### 1. Landing Page
A polished static landing page for a fictional product/service.  
**Highlights:**
- Sticky navigation bar
- Hero section with headline, subheadline, and CTA
- Features, About, and Testimonials sections
- Responsive layout with neat typography

---

### 2. Personal Portfolio
A digital résumé showcasing skills, projects, and contact information.  
**Highlights:**
- Hero/profile section with name, role, and avatar
- About Me and Skills sections
- Projects grid with GitHub placeholders
- Contact section with email/social links
- Smooth scroll navigation and responsive design

---

### 3. Temperature Converter
An interactive tool to convert between Celsius, Fahrenheit, and Kelvin.  
**Highlights:**
- Numeric input validation
- Dropdown unit selector
- Convert button with simultaneous output
- Absolute zero check with error handling
- Clean, centered UI layout

---

### 4. Calculator
A browser‑based calculator for basic arithmetic operations.  
**Highlights:**
- Display screen for input/result
- Numeric and operator buttons (+, −, ×, ÷)
- Equals, Clear, and Backspace functionality
- Division‑by‑zero error handling
- Operator chaining supported
- CSS Grid for button layout

---

### 5. Tribute Page
A visually engaging tribute page dedicated to **Albert Einstein** (customizable for any figure).  
**Highlights:**
- Title and tagline with prominent image
- Biography section with multiple paragraphs
- Timeline of key achievements
- Styled quote block
- Multiple background colours and font styles
- Responsive layout

## 🛠️ Tech Stack
- **HTML5** for semantic structure

## 📖 Usage
1. Clone or download this repository.
2. Navigate to the project folder you want to explore.
3. Open `index.html` in your browser.
4. Customize text, images, and styles to make it your own.

- Responsive design with Flexbox and Grid
- Clean typography and consistent branding
