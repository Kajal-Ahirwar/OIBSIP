# NovaBooks Landing Page

A visually polished static landing page built with **HTML5** and **CSS3**.  
This project demonstrates foundational layout skills including responsive design, typography, and section structuring.

---

## 🚀 Features Implemented
- **Sticky Navigation Bar** with 3 links (Features, About, Testimonials)
- **Hero Section** with headline, subheadline, and call-to-action button
- **Content Sections**:
  - Features (grid layout)
  - About (alt background)
  - Testimonials (quotes grid)
- **Footer** with placeholder contact/social links
- **Consistent Colour Palette** (purple/blue gradient + neutral grays)
- **Responsive Layout** using Flexbox and media queries
- **Clean Typography** with distinct heading and body font sizes
- **No Element Overlap** — intentional padding, margin, and box-sizing applied

## 🎨 Design Notes
- **Colour Palette**: Gradient hero (purple → blue), neutral gray backgrounds, white cards
- **Typography**: 
  - Headings: bold, larger font sizes
  - Body: clean sans-serif, readable line spacing
- **Layout**: Flexbox grids for features and testimonials, responsive stacking on mobile

---

## 📱 Responsiveness
- Desktop: Multi-column grids for features/testimonials
- Tablet/Mobile: Stacked layout with adjusted font sizes
- Media queries ensure readability and usability across screen widths

---

## 🛠️ Tech Stack
- **HTML5** for semantic structure
- **CSS3** for styling and responsive design
- No JavaScript required

---

## 📖 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Customize text, branding, and links to fit your product/service.
