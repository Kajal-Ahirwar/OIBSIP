# 🌟 Tribute Page - Albert Einstein

A visually engaging tribute page dedicated to **Albert Einstein**, designed with **HTML5** and **CSS3**.  
This project highlights his life, achievements, and legacy in a clean, responsive layout.

---

## 🚀 Features
- **Page Title & Tagline** introducing the subject
- **Prominent Image** (royalty-free from Wikimedia Commons)
- **Biography Section** with 4 detailed paragraphs
- **Timeline Section** listing key achievements
- **Quote Block** styled distinctly
- **Multiple Background Colours** for visual contrast
- **Two Font Styles** (serif for headings/quotes, sans-serif for body text)
- **Responsive Layout** with media queries

## 🎨 Design Notes
- **Colour Scheme**: Blue hero section, gray biography background, purple quote section
- **Typography**: 
  - Serif (Georgia) for headings and quotes
  - Sans-serif (Arial) for body text
- **Layout**: Sections stacked vertically with clear spacing and alignment

---

## 📱 Responsiveness
- Desktop: Full-width sections with centered content
- Mobile: Adjusted font sizes and padding for readability
- Image scales appropriately across screen sizes

---

## 🛠️ Tech Stack
- **HTML5** for semantic structure
- **CSS3** for styling and responsive design
- *(Optional)* JavaScript for future enhancements

---

## 📖 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Customize the subject, biography, timeline, and quote to create your own tribute page.
