# 🌡️ Temperature Converter Website

An interactive web tool built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.  
This project allows users to convert temperature values between **Celsius**, **Fahrenheit**, and **Kelvin** with real-time validation and user-friendly error handling.

---

## 🚀 Features
- **Numeric Input Field** with validation (rejects non-numeric values)
- **Unit Selector** (Celsius, Fahrenheit, Kelvin)
- **Convert Button** to trigger calculations
- **Simultaneous Output** showing all converted units
- **Absolute Zero Check** with clear error message for invalid inputs
- **Clean, Centered UI** with consistent branding
- **Responsive Layout** for desktop and mobile

## 📖 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter a numeric temperature value.
4. Select the input unit (Celsius, Fahrenheit, Kelvin).
5. Click **Convert** to view results in all units.
